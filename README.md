# 🔥 Turbojet Engine Prototype

A student-engineered turbojet engine prototype designed, fabricated,
assembled, and tested as a mechanical engineering project.

## 📌 Overview

This project focuses on the design and development of a small-scale
turbojet engine prototype. The project covers the complete engineering
workflow from conceptual design and CAD modelling to fabrication,
assembly, and testing.

The main objective was to understand the mechanical and thermodynamic
principles involved in a turbojet engine while gaining practical
experience in component design, manufacturing, and assembly.

---

## ⚙️ Project Features

- Turbojet engine prototype design
- CAD modelling of engine components
- Turbine and vane design
- Mechanical shaft and rotor assembly
- Fabrication using sheet metal and machined components
- Assembly and testing
- Experimental evaluation

---

## 🧩 Major Components

- Compressor
- Combustion chamber
- Turbine
- Turbine vanes
- Shaft
- Engine casing
- Rotor assembly
- Exhaust section

---

## 📐 Design Parameters

| Parameter | Value |
|---|---:|
| Turbine vane angle | 42° |
| Number of vane blades | 18 |
| Shaft material | Aluminium |
| Casing material | Aluminium sheet |
| Base material | Wood |
| Shaft support | Stainless steel rod |

> refined.
